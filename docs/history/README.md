# Historical site assets

These files preserve earlier site designs and are excluded from the Jekyll build by the `docs` rule in `_config.yml`.

- [legacy-portfolio-launch.json](legacy-portfolio-launch.json): the previous static portfolio debug configuration. It targets a removed `/lang/JaeyeongChoi.ko.html` page on port 5500, so it is no longer an active editor launch configuration. Use the preview commands in the [repository README](../../README.md) for the current Jekyll site.
- [legacy-jc-favicon.svg](legacy-jc-favicon.svg): the earlier JC monogram design reference. The current served icons live in [assets/img/favicons](../../assets/img/favicons/). This file is not their generation source.

Both historical files were relocated without changing their bytes on 2026-09-14.
